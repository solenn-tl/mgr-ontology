# Talk module - Glossary

| Term (English / Français) | Category | Definition / Description |
| --- | --- | --- |
| **Talk / Conférence** | Class | An individual talk, lecture, forum, or roundtable presentation. |
| **Talk set / Ensemble de conférences** | Class | A set of talks, lectures, forums, or roundtable presentations linked by a common theme or purpose. |
| **Talk type / Type de conférence** | Class | Types of talks like lecture, forum, or roundtable presentation. |
| **Context event / Événement contextuel** | Class | An event that provides context for a talk or talk set, such as a festival, exhibition, or cultural season. |
| **Context event type / Type d'événement contextuel** | Class | Types of context events like festival, exhibition, or cultural season. |
| **is organized in context of / est organisé dans le contexte de** | Object Property | Relates a talk or talk set to a context event that provides additional context for the event. |
| **is organized by / est organisé par** | Object Property | Relates a talk or talk set to the organization responsible for organizing the event. |
| **takes place at / a lieu à** | Object Property | Relates a talk or talk set to the location where the event takes place. |
| **is part of talk set / fait partie du cycle** | Object Property | Relates an individual talk to the talk set it belongs to. |
| **event type / type d'événement contextuel** | Object Property | Relates a context event to its type. |
| **talk type / type de conférence** | Object Property | Relates a talk or talk set to its specific type. |
| **has time / a pour temps** | Object Property | Relates a talk, talk set, or context event to a temporal entity (instant or interval). |
| **has speaker / a pour conférencier** | Object Property | Relates a talk to a person acting as a speaker. |
| **is speaker in / est conférencier dans** | Object Property | Inverse relation indicating a person is a speaker in a talk. |
| **has moderator / a pour modérateur** | Object Property | Relates a talk to a person acting as a moderator. |
| **is moderator of / est modérateur de** | Object Property | Inverse relation indicating a person moderates a talk. |
| **has guest speaker / a pour conférencier invité** | Object Property | Relates a talk to an invited guest speaker. |
| **is guest speaker of / est conférencier invité de** | Object Property | Inverse relation indicating a person is a guest speaker in a talk. |
| **has audience member / a pour membre du public** | Object Property | Relates a talk to an audience member. |
| **is audience member of / est membre du public de** | Object Property | Inverse relation indicating attendance in a talk. |
| **has contributor / a pour contributeur** | Object Property | Relates a talk to a contributing person. |
| **includes work / inclut l'œuvre** | Object Property | Relates a talk to a featured creative work. |
| **has topic / a pour sujet** | Object Property | Relates a talk to a topic or concept. |
| **Syracuse ID / identifiant Syracuse** | Datatype Property | External Syracuse system identifier. |
| **documentId / identifiant documentId** | Datatype Property | Document identifier. |
| **title / titre** | Datatype Property | The primary title of the resource. |
| **subtitle / sous-titre** | Datatype Property | The subtitle of the resource. |
| **summary / résumé** | Datatype Property | A summary, abstract, or description of the resource. |
| **URL on pad.philharmoniedeparis.fr** | Datatype Property | Web page URL pointing to the resource player or page. |
| **Panel discussion / Table ronde** | Concept | Discussion structurée entre plusieurs spécialistes sur un sujet donné. |
| **Keynote** | Concept | Conférence d'un seul spécialiste invité. |
| **Exhibition / Exposition** | Concept | Context event type representing an exhibition. |
| **Cultural season / Saison culturelle** | Concept | Context event type representing a cultural season. |
